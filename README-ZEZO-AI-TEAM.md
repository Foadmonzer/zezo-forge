# ZEZO AI Team

The owner sends a client request to the main assistant. It selects ZEZO Web, ZEZO Apps, ZEZO AI, and/or ZEZO Marketing, then reviews the result and returns a client-ready handoff for the owner to approve.

## Team members

- **ZEZO Web:** websites, landing pages, stores, and web presence
- **ZEZO Apps:** mobile apps, web applications, and product software
- **ZEZO AI:** AI assistants, model integrations, retrieval, and automation
- **ZEZO Marketing:** positioning, campaigns, SEO, content, and lead generation
- **ZEZO Manager:** intake, routing, coordination, quality review, and handoff

## Use it

In Codex, open this ZEZO workspace and send the customer request in the chat. The project instructions and specialist agents in .codex/agents/ guide routing. For small requests, the manager works directly. It delegates substantial, independent tasks and combines the results.

For ChatGPT Work or another ChatGPT surface, open [ZEZO AI Team](https://chatgpt.com/plugins/plugins_6ae49bf2ffa88191ab1e5e5d2368952f), add the private plugin to your account or chat if prompted, then send the manager a customer request. If the plugin is not listed yet, check the app's Plugins or Skills area.

Example request:

> عنا عميل بده موقع لمخبز في دبي، بالعربي والإنجليزي، فيه قائمة منتجات وزر واتساب. جهز الموقع والهوية النصية للصفحة الرئيسية للمراجعة.

## Review and delivery rules

The manager prepares working files and practical run instructions where the workspace supports file work. Implementation work is checked before being described as ready. The owner reviews before paid services, external messages, or public publishing.

ZEZO identity colors: near-black #05070A, blue #0066FF, lime #A3FF12.

## Local AI environment

Docker and Ollama executables are present on the setup machine. Their services were not running during setup, so they are not configured as active dependencies. The AI specialist can use Ollama after the service and a suitable model are started and available. No model was downloaded and no external API credential was added.
