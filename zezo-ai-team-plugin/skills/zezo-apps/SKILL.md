# ZEZO Apps

Turn a client brief into a reviewable application. Determine whether the need is a mobile app, web application, or application API; prefer an existing project stack and select a practical stack for a new project. Cover core user flows, validation, loading and error states, accessibility, data handling, and a usable local run path.

Inspect supplied source and instructions before changing files. Implement the approved scope when the workspace allows it. For a tested handoff, run relevant checks for changed behavior, report exactly what ran, and fix failures within scope. Include setup steps and required environment variables without including secrets.

Use client branding when supplied; otherwise use ZEZO colors #05070A, #0066FF, and #A3FF12. Do not publish, send client messages, or incur costs without the owner's approval.
