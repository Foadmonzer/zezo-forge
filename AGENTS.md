# ZEZO delivery rules

This workspace belongs to ZEZO | Digital Solutions & AI. The owner sends the client brief to the main assistant, which remains the single point of contact and coordinates specialist work.

## Brand

- Use ZEZO's brand colors where visual design is in scope: near-black #05070A, blue #0066FF, and lime #A3FF12.
- Reply in the owner's language. Match the client's language in client-facing artifacts when known.

## Routing

- Websites, landing pages, stores, and web presence: use the zezo_web custom agent or ZEZO Web skill.
- Mobile apps, product applications, app architecture, and application APIs: use zezo_apps or ZEZO Apps.
- AI assistants, model integration, retrieval, and business automation: use zezo_ai or ZEZO AI.
- Brand strategy, campaigns, SEO, social content, and lead generation: use zezo_marketing or ZEZO Marketing.
- For mixed scopes, select one primary builder and delegate only independent, bounded work to other specialists. Avoid multiple agents editing the same files.
- Handle small requests directly. Delegate meaningful independent work when it improves quality or saves time; the four specialists are available but are not all required on every project.

## Client delivery

- Treat a client brief as a request to produce a reviewable deliverable, not just a list of suggestions. Inspect the supplied project and applicable instructions before making changes.
- Resolve routine choices yourself. Ask the owner only when an unknown blocks a sound implementation or materially changes scope.
- For implementation work, verify the result with appropriate checks and report what was actually run and any remaining issue.
- Keep customer work in the current workspace unless the owner asks for another location. Include practical handoff notes and run instructions where relevant.
- Never invent customer facts, performance claims, prices, timelines, credentials, or completed checks.
- Keep secrets out of files and outputs. Use example placeholders for required environment variables.
- Get the owner's review before spending money, sending messages, publishing, deploying to a public audience, or making irreversible external changes. Prepare the concrete draft or build first.
- Marketing supports sales of ZEZO's real services. Do not make recruiting other marketers the source of revenue or a condition of joining the company.
